## 1. 지역은 좌표에서 판정한다

`camera` 테이블에 지역 컬럼을 두지 않았습니다. **마이그레이션이 필요 없고**,
좌표를 고치면 지역도 저절로 맞습니다. 컬럼으로 두면 좌표만 고쳤을 때 어긋나
「지도에는 서울인데 목록에는 부산」 같은 상태가 생깁니다.

판정은 `cctv_sources.REGIONS` 의 17개 시도 사각형을 씁니다. 사각형이 서로
겹치므로(서울은 경기 안에, 부산은 경남 안에) **드는 것 중 가장 좁은 것**을
고릅니다.

| 함수 | 하는 일 |
|---|---|
| `cctv_sources.region_of(lat, lng)` | 시도 키. 판정 못 하면 `None` |
| `cctv_sources.region_label(key)` | 사람이 읽는 이름. 모르면 **「지역 미상」** |
| `cameras.group_by_region(cams)` | 지역별로 묶기 (등록 수 많은 순) |
| `cameras.by_region(db, region)` | 해당 지역만 |
| `cameras.delete_region(db, region)` | 일괄 해지 |

> 지역을 알 수 없는 지점도 **버리지 않고 「지역 미상」으로 묶습니다.** 안 보이면
> 해지도 못 합니다.

## 2. S-80 화면 변경

### 2-1. 지역별 등록 현황 · 일괄 해지 (신규)

지역마다 등록 대수를 보여 주고, 그 자리에서 일괄 해지합니다.

**되돌릴 수 없으므로 지역 이름을 그대로 입력해야 해지됩니다.** 버튼 하나로
수십 대가 사라지면 실수 한 번의 대가가 너무 큽니다.

두 가지를 막아 두었습니다.

- **전부 해지 불가** — 한 대도 없으면 화면과 파이프라인이 빈 채로 돌아
  「설정이 날아간 것」과 구분되지 않습니다(단건 삭제와 같은 규칙)
- **감사 로그 기록** — 지역·대수·지점명(최대 20건)을 남깁니다

### 2-2. 서울 CCTV 수집 (신규)

「② 서울 CCTV 수집」 — **인증키가 필요 없습니다.** 지점명으로 걸러낼 수 있고
(예: `남산`), 최대 10~60개소까지 한 번에 불러옵니다.

> ⚠️ 화질은 이 API가 알려주지 않습니다. 등록 뒤
> `scripts/probe_cctv_resolution.py` 로 실측해야 합니다.

### 2-3. 목록에 지역 표시

각 지점 아래 `ID · 지역` 형태로 함께 보입니다.

## 4. **상시 탐지는 켜지 않았습니다**

30개소 모두 도메인은 「사용」, 분석 방식은 **「선택」** 입니다
(`CameraDomain.continuous = False`).

이유가 둘입니다.

1. **테스트를 골라서 하실 수 있어야 합니다.** 화면에서 지점을 고를 때만
   분석이 돕니다.
2. **서울 스트리밍은 고정적 다중 접속 시 차단될 수 있습니다.** 연계 협의
   전에 30개소를 24시간 물고 있으면 안 됩니다.

상시로 바꾸려면 S-80에서 지점별로 「상시」를 켜면 됩니다. 다만 **협의 뒤에
하십시오**(docs 202608160906 조사서 3절).

## 6. 고친 결함 — 라우트 순서

`/settings/cameras/region/delete` 를 `{camera_id}/delete` **뒤에** 등록했더니
`camera_id="region"` 으로 잡혀 「카메라를 찾을 수 없습니다」로 끝났습니다.
FastAPI 는 등록 순서대로 맞추므로 **구체적인 경로를 먼저 등록**해야 합니다.

시험이 잡아냈고, 해당 위치에 주석을 남겼습니다.
