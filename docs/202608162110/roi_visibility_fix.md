# 탐지 지정 변경 시 ROI 사라짐 — 원인 규명과 수정

## 0. 결론 먼저

○ **ROI 데이터는 지워지지 않고 있었습니다.** 재현으로 확인했습니다 —
  탐지 지정을 꺼도 `camera_rois` 행은 그대로이고, 다시 켜면 그대로 쓰입니다

○ **사라진 것은 화면이었습니다.** ROI 편집기와 목록이 「사용」으로 지정된
  도메인만 보여 주고 있었습니다

○ **그럼에도 실제 손실이 날 수 있는 문제였습니다.** 보이지 않으면 운영자는
  다시 그립니다 — 그것이 진짜 손실입니다

○ 회귀 **967건 통과 · 실패 0**

## 1. 신고 내용

> CCTV를 등록하고 등록된 CCTV의 ROI를 설정하였는데, 탐지지정에서 설정을
> 변경하면 ROI가 사라지는 상황이 발생

---

## 2. 재현 결과 — 데이터는 남아 있었습니다

카메라를 만들고 침수 ROI를 저장한 뒤, 탐지 지정을 「침수 끄고 인파 켬」으로
바꿔 봤습니다.

```
[1] ROI 저장 직후      camera_rois 행수 = 1
                       shapes = road_roi · low_point_roi · lane_threshold_line
[2] 탐지 지정 변경 후   camera_rois 행수 = 1   ← 그대로
                       남음: REPRO-1/flood  [road_roi, low_point_roi, lane_threshold_line]
[3] 침수 다시 켠 후     shapes = road_roi · low_point_roi · lane_threshold_line
```

**구조상 그럴 수밖에 없습니다.**

| 저장 대상 | 테이블 |
|---|---|
| 탐지 지정(사용/상시) | `camera_domains` |
| ROI(관심영역) | `camera_rois` |

`set_domains()` 는 `camera_domains` 만 건드리고, ROI 삭제는 **카메라 자체를
지울 때(CASCADE)만** 일어납니다.

---

## 3. 진짜 원인 — 화면이 숨기고 있었습니다

| # | 위치 | 문제 |
|---|---|---|
| ① | `service/routes_cameras.py` (ROI 편집기) | 「사용」으로 지정된 도메인만 탭에 표시 |
| ② | `templates/cameras.html` (목록 ROI 열) | 「사용」일 때만 배지 표시 |

침수 ROI를 그려 둔 뒤 탐지 지정에서 침수를 끄면, **탭도 배지도 사라집니다.**
화면상으로는 지워진 것과 구분이 되지 않습니다.

### 왜 심각한가

보이지 않으면 운영자는 **다시 그립니다.** 그러면
- 이미 있는 ROI를 덮어쓰거나
- 「이 제품은 설정이 자꾸 날아간다」는 인식이 남습니다

**데이터가 멀쩡한데 화면이 거짓말을 하고 있었습니다.**

---

## 4. 고친 것 세 가지

### ① ROI 편집기 — 탭을 남깁니다

탐지 지정이 꺼진 도메인이라도 **저장된 ROI가 있으면 탭을 유지**하고
「침수·교통위험 · 미지정」으로 표시합니다.

그 탭을 열면 안내가 뜹니다.

> 이 탐지서비스는 지금 **이 지점에 지정돼 있지 않습니다.** 설정한 영역은
> **지워지지 않고 보관**되며, CCTV 관리(S-80)의 「탐지 지정」에서 다시
> **사용**으로 바꾸면 그대로 쓰입니다.

**기본 탭은 지금 쓰는 도메인이 먼저입니다** — 보관 탭이 먼저 열려 「지금 안 쓰는
영역」을 만지게 하면 안 됩니다.

### ② 목록 — 「보관」 배지

ROI 열에 회색 배지(`침수 보관`)를 띄웁니다. 아무 표시도 없으면 「지워졌다」로
읽힙니다.

### ③ 탐지 지정을 끄는 순간 알려 줍니다

저장 메시지에 다음을 덧붙입니다.

> …**침수·교통위험**의 ROI는 지워지지 않고 보관됩니다 — 다시 「사용」으로
> 바꾸면 그대로 쓰입니다.

## 5. 시험

| 구분 | 결과 |
|---|---|
| 신규 시험 | **8건** (`tests/service/test_roi_persistence.py`) |
| 전체 회귀 | **967건 통과 · 3건 건너뜀 · 실패 0** (5분 11초) |

### 시험이 못박은 것

- 탐지 지정을 꺼도 `camera_rois` 행이 남는다
- **다시 켜면 좌표가 그대로다** (다시 그릴 필요 없음)
- 꺼진 동안에도 편집기 탭·목록 배지에 보인다
- 꺼진 탭을 열면 「보관 중」 안내와 함께 **좌표가 실제로 실린다**
- 기본 탭은 쓰고 있는 도메인이 먼저다
- 끄는 순간 「보관됩니다」를 안내하고, 실제로도 안 지운다

## 6. 실제 운영 데이터 확인 — 8개 지점 18건이 숨어 있었습니다

수정 후 라이브에서 조사한 결과, **탐지 지정이 꺼져 있어 화면에서 보이지
않던 ROI가 8개 지점에 18건** 있었습니다. 전부 데이터는 멀쩡했고, 이제
편집기 탭과 목록에 나타납니다.

| 지점 | 보관 중이던 ROI |
|---|---|
| BLOCK-BUSANSTN | 침수 · 인파 · 노면 |
| BLOCK-GUANGBOK | 침수 · 인파 · 노면 |
| BLOCK-GUANGBOK1 | 침수 · 인파 · 노면 |
| BLOCK-BEXCO2 | 침수 · 노면 |
| BLOCK-JAESONG | 침수 · 노면 |
| BLOCK-OLYMPIC | 침수 · 노면 |
| SEOUL-126 | 침수 · 노면 |
| BLOCK-BEOMNAEGOL | 침수 |

> **BLOCK-BEXCO2 가 이 문제의 전형입니다.** 세 도메인이 모두 「미사용」이라
> 편집기가 침수 탭 하나만(빈 화면으로) 띄웠고, 그려 둔 **노면 ROI 는 화면
> 어디에서도 열 수 없었습니다.**

## 7. 운영자께 드리는 말씀

**이미 그려 두신 ROI는 모두 살아 있습니다.** 탐지 지정을 껐다 켜신 지점이
있다면, 다시 「사용」으로 바꾸시면 예전 영역이 그대로 나타납니다. 다시
그리실 필요 없습니다.
