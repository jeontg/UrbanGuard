## 파일 저장 규칙

### 일시 폴더

문서를 만들거나 고칠 때마다 **`docs\<YYYYMMDDHHMM>\`** 폴더를 만들어 그 안에
저장합니다. 폴더가 시점을 나타내므로 **파일명에는 일시를 붙이지 않습니다.**

```
docs\202608131503\        ← 최신
    system_architecture.md    db_design_spec.md
    interface_spec.md         security_design.md
    privacy_assessment.md     test_plan_report.md
    install_guide.md          operator_manual.md
    development_status.md
    UrbanGuard_화면설계서_v4.7_최종.pptx   ← 대외 제출용
    UrbanGuard_문서목록.hwpx      ← 그 시점의 전체 문서 현황

docs\202608120441\        ← 이전 판 (대조용)
```

**각 일시 폴더에 `UrbanGuard_문서목록.hwpx` 를 함께 넣습니다.** 폴더 안 파일만이
아니라 그 시점의 `docs\` **전체 현황**을 담습니다.

### ★ 미결 과제는 한 곳에 모읍니다

**[pending_tasks.md](pending_tasks.md) — 미결 과제 대장.**

회차마다 「확인이 필요한 것」이 붙는데, 회차가 쌓이면서 **어디에 무엇이 남아
있는지 알 수 없게 됐습니다.** 그래서 흩어진 것을 모으고 앞으로 나오는 것도
거기에 더합니다. **처리하면 지우고, 「안 하기로 정한 것」은 남깁니다** —
같은 논의가 다시 올라오지 않게 하려는 것입니다.

⚠️ 대장에는 근거를 확인한 항목(**✔**)과 확인하지 못한 항목(**⚠**)이 섞여
있습니다. **⚠ 를 사실처럼 제안서에 쓰면 안 됩니다.**
