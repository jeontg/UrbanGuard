# 폐쇄망 자산 반입 — hls.js 를 우리 서버에서 내보냅니다

작성 2026-08-19 · UrbanGuard

---

## 0. 결론 먼저

**화면이 인터넷에서 받아오던 파일 하나를 저장소로 들여왔습니다.** 이제
UrbanGuard 화면은 **바깥을 한 번도 부르지 않습니다.**

| 항목 | 전 | 후 |
|---|---|---|
| hls.js 출처 | `cdn.jsdelivr.net` (인터넷) | `/static/vendor/hls.min.js` (우리 서버) |
| 폐쇄망 관제실 | **실시간 영상 안 나옴 + 화면 전체 비어 있음** | 정상 |
| 경남 제안요청서 PER-009 | **위반** | 충족 |
| 되돌아갈 위험 | 사람 눈으로 못 잡음 | **시험 38건이 막음** |

전체 회귀 **1,239건 통과** (3 skip).

## 1. 무엇이 문제였나

`index.html` 마지막에 이런 줄이 있었습니다.

```html
<script src="https://cdn.jsdelivr.net/npm/hls.js@1.5.13/dist/hls.min.js"></script>
<script src="/static/app.js"></script>
```

첫 줄은 **인터넷에 있는 파일**을 받아오는 줄입니다. 개발 PC 에서는 인터넷이
되니 **아무 문제 없어 보입니다.** 납품처인 **폐쇄망(망분리) 관제실**에 넣는
순간 드러납니다.

### 왜 「영상만 안 나오는」 정도로 끝나지 않는가

★ **이것이 이번 건에서 가장 중요한 부분입니다.**

`<script src=...>` 는 **순서대로 실행되는** 방식입니다. 브라우저는 첫 줄을
받아오려고 시도하고, **받아올 때까지 그 아래를 실행하지 않습니다.**

폐쇄망에서는 그 요청이 곧바로 거절되는 게 아니라 **응답을 기다리다 시간이
다 지나서야** 실패합니다. 그동안 아래 `app.js` 가 멈춰 있습니다.

즉 증상은 **「영상이 안 나온다」가 아니라 「화면이 통째로 비어 있다」**입니다.
지도도, 지점 카드도, 위험등급 타임라인도 그려지지 않습니다. 관제요원이 보는
것은 빈 페이지입니다.

### 규격 위반이기도 합니다

경남 제안요청서 **PER-009** 원문입니다.

> 「시스템 운영 시 **외부 인터넷 연결이 필수적으로 요구되지 않는 구조**를
> 제공하여야 한다」

⚠️ 평가위원이 이 항목을 확인하려고 **관제 PC 의 인터넷을 끊고 화면을 열어
보면**, 위 증상이 그대로 나옵니다.

## 2. hls.js 가 무엇이길래 필요한가

CCTV 스트림은 대부분 **HLS** 형식(`....m3u8`)입니다. 이걸 브라우저가 직접
재생하는 것은 **Safari 뿐**입니다. 관제 PC 는 대부분 Chrome·Edge 라서,
그 브라우저들이 재생할 수 있게 풀어 주는 라이브러리가 필요합니다.

**빼는 선택지는 없습니다.** 빼면 Chrome·Edge 에서 실시간 영상이 안 나옵니다.
그래서 **어디서 받아오느냐**만 남고, 답은 「우리 서버에서」입니다.

## 3. 어떻게 고쳤나

### 3-1. 파일 반입

```
src/tot_dashboard/service/static/vendor/
├── hls.min.js            413,181 B
├── hls.js-LICENSE.txt      1,338 B
└── README.md
```

| 항목 | 값 |
|---|---|
| 버전 | hls.js **1.5.13** |
| SHA-256 | `e5753b10fc65eae35f21883e684d22c43ce66de968d35166792585b9b8a3f1a2` |
| 라이선스 | **Apache-2.0** |
| 저작권 | Copyright (c) 2017 Dailymotion |
| 출처 | https://github.com/video-dev/hls.js |
| 반입일 | 2026-08-19 |

⚠️ **라이선스 사본을 반드시 함께 둡니다.** 최소화된 `hls.min.js` 안에는
**라이선스 표기가 들어 있지 않습니다.** Apache-2.0 은 재배포할 때 사본을
함께 두도록 요구하므로, `hls.js-LICENSE.txt` 를 지우면 **라이선스 위반**이
됩니다.

> 「라이선스 문제는 고려하지 말자」고 하신 것은 **AGPL 모델 선택**에 대한
> 말씀이었습니다. 재배포 시 사본을 동봉하는 의무는 성격이 다르고 비용도
> 들지 않아 그대로 지켰습니다.

### 3-2. 화면 수정

`index.html` 한 줄입니다.

```html
<script src="/static/vendor/hls.min.js"></script>
```

바꾼 이유를 **주석으로 남겼습니다.** 이유를 모르면 다음 사람이 「CDN 쓰는 게
더 빠른데?」 하고 되돌립니다.

### 3-3. 되돌아가지 못하게 막기

★ **이 건의 진짜 위험은 「지금 더러운 것」이 아니라 「다시 더러워지는 것」**
입니다. 새 화면을 만들 때 CDN 한 줄 붙이는 것은 너무 쉽고, 개발 PC 에서는
멀쩡히 보입니다.

`tests/service/test_no_external_assets.py` 를 새로 만들었습니다.

| 시험 | 보는 것 |
|---|---|
| 템플릿 33개 각각 | `src`·`href` 에 바깥 주소가 없는가 |
| `static/*.js` 전부 | 실행 중에 바깥을 부르지 않는가 |
| `hls.min.js` | 있는가 · 손상되지 않았는가 (크기) |
| `hls.js-LICENSE.txt` | 있는가 · Apache-2.0 · Dailymotion 표기 |
| `vendor/README.md` | 출처·SHA-256 이 적혀 있는가 |
| `index.html` | 반입본을 쓰는가 |

**총 38건.**

## 4. 시험을 만들면서 시험이 틀린 것을 세 번 잡았습니다

시험은 「통과했다」가 아니라 **「제대로 잡는가」**를 확인해야 합니다.

### ① `http://www.w3.org/2000/svg` 를 위반으로 잡았습니다

**주소처럼 생겼지만 주소가 아닙니다.** SVG 요소를 만들 때 쓰는 **식별자**이고
브라우저가 받아오지 않습니다. 이걸 막으면 **SVG 를 못 그립니다.**

→ XML 이름공간 목록을 만들어 제외했습니다.

### ② README 의 `SHA-256` 을 못 찾았습니다

`"sha256" in text` 로 봤는데 문서에는 `SHA-256` (하이픈)으로 적혀 있었습니다.
**문서가 맞고 시험이 틀렸습니다.**

→ `re.search(r"sha-?256", ...)`

### ③ 「왜 바꿨는지」 적은 주석을 위반으로 잡았습니다

주석에 옛 CDN 주소를 남겨 뒀는데 시험이 그걸 잡았습니다.

⚠️ **이대로 두면 다음 사람은 설명을 지우는 쪽을 고릅니다.** 시험을 통과시키는
가장 쉬운 길이 「경위를 지우는 것」이 되면 안 됩니다.

→ 실제로 **받아오는 자리**(`src=`·`href=`)만 보도록 고쳤습니다.

## 5. 시험이 진짜로 잡는지 확인했습니다

★ **통과하는 시험은 아무것도 증명하지 않습니다.** 일부러 `index.html` 을
옛 CDN 주소로 되돌려 봤습니다.

```

FAILED test_index_가_반입본을_쓴다
2 failed, 36 passed
```

**의도대로 2건이 실패했습니다.** 되돌린 뒤 38건 전부 통과를 다시 확인했고,
서버가 실제로 파일을 내보내는지도 확인했습니다.
