## 2. 항목별 상세

### ① 핵심 결함유형 선정 — ✔ 됨

`core/vocabulary.py` 의 `DEFAULT_HAZARD_TYPES` 11행입니다.

| 도메인 | 유형 |
|---|---|
| 침수 | 침수 · **지하차도 침수** · **배수로 침수** · 하천 범람 |
| 인파 | 인파 · 인파 밀집 · 배회 |
| 노면 | 노면 · 노면 파손 |
| (도메인 없음) | 산불 확산 · 태풍 피해 |

★ **`detectable` 칸으로 「어휘 등록」과 「탐지 가능」을 구분**합니다. 하천
범람·산불·태풍은 발주 요구라 어휘는 넣되 **모델이 없다는 사실을 표시**합니다.
이 구분이 없으면 화면이 「우리는 산불도 탐지한다」는 거짓말을 만듭니다.

### ② 학습데이터 파이프라인 — △ (수집·전처리 ✔ / 키프레임·게이트 △)

**있는 것**

| 기능 | 위치 |
|---|---|
| 강우 연동 자동 수집(10분 주기, 임계 이상만) | `scripts/collect_flood_frames.py` |
| 노면 상시 순회 중 자동 수집 | `road/dataset_collector.py` |
| 영상 편입(업로드) | `dataset_collector.ingest_video()` |
| 균등 간격 프레임 샘플링 | `dataset_collector._pick()` |
| **마스킹 실패 시 저장 안 함** | `dataset_collector` |
| 수집 이력(`meta.jsonl`) | 〃 |
| 공개 데이터셋 변환 | `prepare_rdd2022_yolo.py` · `prepare_svrdd_yolo.py` |
| 음성표본 보충 | `add_negative_samples.py` |

> **마스킹 게이트의 근거가 코드에 적혀 있습니다** — 「ROI 작업용 정지영상은
> 마스킹이 실패해도 띄운다. 한 번 보고 버리는 화면이라 그래야 작업이 성립한다.
> **학습 데이터는 반대다. 오래 보관하는 파일이므로 가리지 못했으면 남기지
> 않는다.**」

⚠️ **없는 것 — 두 가지입니다**

**ⓐ 유사도 기반 중복 제거(pHash·SSIM)**

`_pick()` 은 관측 창 안에서 **균등 간격**으로 뽑습니다. 연속 프레임 중복은
완화되지만, **다른 시각의 같은 장면**은 못 거릅니다. 야간에 화면이 사실상
멎어 있으면 같은 그림이 계속 쌓입니다.

**ⓑ 프레임 단위 화질 게이트**

흐림·과노출·야간 판정이 **수집 시점에** 없습니다.
`assess_road_label_feasibility.py` 가 선명도를 재지만 그것은 **지점 선별**이지
프레임 게이트가 아닙니다.

> ★ **노면 모델이 4번 실패한 패턴이 이것과 맞닿아 있습니다** — 자기 데이터셋
> 점수는 오르는데 부산 CCTV에서는 차선을 균열로 읽었습니다.

### ③ 품질검증·정제 — △ (지점 선별만)

**있는 것 — `assess_road_label_feasibility.py`**

라벨링 인력을 넣기 **전에** 「이 지점은 사람도 박스를 그을 수 없다」를 걸러
냅니다.

- **해상도**(1차 기준) — 짧은 변 240px 이면 노면이 몇 픽셀
- **선명도**(라플라시안 분산) — **하한 검사용이지 순위 지표가 아님**을 코드가 명시

★ 다만 이것은 **③보다 ②(품질게이트)에 가깝습니다.**

⚠️ **③이 요구하는 것은 여전히 0건입니다**

| 요구 | 상태 |
|---|---|
| 표본 QA | ✗ |
| 매뉴얼 코드 대비 **라벨 감사** | ✗ |
| 정제 기준 | ✗ |
| 검증보고 | ✗ |

> ⚠️ **지금은 라벨이 맞는지 아무도 보지 않습니다.**
> `eval_flood_water_model.py` 는 **모델 평가**이지 라벨 감사가 아닙니다.
> 이게 없으면 「침수 val F1 0.9392」의 **분모를 믿을 근거가 없습니다.**

> **가장 값싸게 메울 수 있는 칸입니다** — 입력(관제요원 판정)은 **이미 쌓이고

### ⑤ 전이학습 없이 2~3개 알고리즘 조합 — ✗ 정면으로 어긋남

```python
# 침수 — ImageNet 백본 + 랜덤 헤드
model = builder(weights=None, weights_backbone="DEFAULT", num_classes=2)

# 노면 — v1 가중치에서 이어 학습
model = YOLO(V1_BEST)
```

**둘 다 전이학습입니다.** 그리고 도메인마다 **알고리즘 1종**입니다(조합 아님).

⚠️ **다만 이 조항의 해석은 확인이 필요합니다.**

| 해석 | 침수 | 노면 |
|---|---|---|
| ImageNet 백본까지 금지 | ✗ 위반 | ✗ 위반 |
| 완성모델 재사용 금지 | **△ 통과 가능** | ✗ 위반 |

> **원문 없이는 제가 판단할 수 없습니다.** 통상 「전이학습 없이」는 「타 기관
> 완성모델을 그대로 가져다 쓰지 말라」는 뜻인 경우가 많지만, **이것은 제
> 추측이며 확인하지 못했습니다.**

⚠️ **from scratch 는 데이터 요구량이 10~100배**입니다. 지금 침수 자체 데이터가
**1,570장**인데 그 규모로는 성립하지 않습니다. 조항 해석이 사업 규모를 바꿉니다.

어느 이름으로도 **0건**입니다.

| 모듈 | 실제로 하는 일 | MLOps 요구 대비 |
|---|---|---|
| `model_registry` | 파일을 **스캔해 목록** 생성 | 버전관리 **아님** |
| `model_probe` | **한 번 대 보는** 도구 | 결과를 **저장하지 않음** |
| `model_ops` | 운영 모델 **수동 선택** | 자동 배포 **아님** |

**「성능비교」를 하려면 비교할 기록이 남아야 하는데 남지 않습니다.**

⚠️ **그리고 자동 배포는 아직 위험합니다.** 2026-08-19 오후에 겪은 일입니다 —
침수 모델이 **적재에 실패해 3개 지점 전부에서 안 돌고 있었는데**
(`models_loaded: 0`), 화면은 모델 경로와 라이선스를 그대로 띄웠습니다.
**맑은 날에는 눈으로 구분되지 않습니다.**

> ★ **배포 검증이 자동 배포보다 먼저입니다.** 검증 없는 자동 배포는
> **망가진 모델을 자동으로 퍼뜨립니다.**
