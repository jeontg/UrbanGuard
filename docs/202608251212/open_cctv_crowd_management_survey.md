## 0. 결론 먼저

○ **당장 "인파관리 전용"으로 공개된 CCTV는 국내·해외 어디에도 없습니다.**
　모두 **교통 소통정보용** 카메라이거나(도로·교차로를 향함), **해수욕장
　안전용**처럼 목적이 다른 카메라를 인파 판단에 "겸용"하는 수준입니다.

○ **방범·다중이용시설 CCTV(진짜 인파가 몰리는 광장·역사·상점가)는 국내에서
　구조적으로 받을 수 없습니다** — 「개인정보 보호법」 제25조상 지자체
　CCTV통합관제센터 전용망으로만 흐르고 외부 제공 창구가 없습니다(이미
　`core/cctv_sources.py`에 기록된 제약과 동일).

○ 그래도 실사용 가능한 후보는 있습니다 — **국내는 해양수산부 해수욕장
　CCTV(여름철 해변 인파)**, **해외는 런던 TfL JamCams(공식 오픈데이터,
　보행자 탐지 학술 선례 있음)**가 가장 유력합니다. 상세는 아래 표 참고.

○ 국내 최대 규모 후보 2건(경찰청 UTIC, 해양수산부 연안포털)은 **실제 영상
　스트림 규격을 이번 조사로 확인하지 못했습니다** — 담당 기관에 직접
　문의가 필요합니다.

## 1. 왜 "인파관리 전용" 오픈 CCTV가 없는가

| 구분 | 이유 |
|---|---|
| 방범 CCTV(광장·역사·상점가) | 「개인정보 보호법」 제25조 — 지자체 CCTV통합관제센터 전용망 안에서만 흐름. 외부 제공 창구 자체가 없음 |
| 교통 CCTV(ITS·TOPIS 등) | 목적이 "소통정보"라 도로·교차로를 향함. 인파는 화면 가장자리에 우연히 잡힐 뿐 |
| 해외 교통 카메라(TfL·NYC 등) | 마찬가지로 교통 목적. 다만 교차로 카메라 중 **보행자 신호·횡단보도가 함께 잡히는 지점**은 인파 탐지 학습에 실사용된 선례가 있음(1-1절) |
| 해수욕장·관광 CCTV | 목적이 "안전 감시"라 인파 밀집과 실제로 상관관계가 있어 **가장 근접한 대안** |

이 구조 자체가 `docs/road_surface_management_plan.md`가 겪은 **도메인 갭**
문제와 비슷한 위험을 안고 있습니다 — 교통 카메라로 학습하면 "도로를 보는
각도"에 맞춰지고, 실제 우리가 필요한 "광장·역사를 내려다보는 각도"와 다를 수
있습니다. 후보를 고를 때 **카메라 화각(부감 각도)이 실제 배치 환경과
비슷한지**를 반드시 확인해야 합니다.

## 2. 국내

### 2-1. 이미 이 프로젝트에 연동돼 있는 것 (참고)

| 소스 | 상태 | 비고 |
|---|---|---|
| 국가교통정보센터(ITS) OpenAPI | ✔ 연동됨 (`core/cctv_sources.py`) | 전국 17개 시도, 인증키 필요, `cctvType=1`(실시간 스트리밍) 제공. **도로 소통정보용** — 교차로 지점 중 일부만 보행자가 함께 보임 |
| 서울시 TOPIS | ✔ 연동됨 (`core/topis_sources.py`) | 인증키 불필요. ⚠ **공식 제공 창구가 아님**(웹 화면이 쓰는 비공식 경로), 다중 접속 시 자동 차단 안내 있음 |

### 2-2. 신규 후보

| # | 소스 | 성격 | 인파관리 적합도 | 접근 방법 | 제약·확인 필요 사항 |
|---|---|---|---|---|---|
| 1 | **국립해양조사원 「안전해(海)」 해수욕장 CCTV** | 해수욕장 안전 감시(이안류·해무) | **★★ 여름철 해변 인파에 근접** | 앱 제공(45개소), 웹은 `coast.mof.go.kr` 연안포털 | ⚠ 이번 조사로는 **영상 API 개방 여부를 확인하지 못함** — 웹뷰어는 클릭 시 개별 영상만 재생, 스트림 URL 직접 제공 안 보임. **고객지원센터(051-773-5694) 문의 필요**. 여름철(이안류 감시 6~9월) 한정 운영 지점이 있어 연중 상시는 아닐 수 있음 |
| 2 | **경찰청 교통 CCTV 영상정보 (UTIC)** | 교통 소통정보 | 낮음(교차로 일부만) | `data.go.kr/data/15148511` → UTIC 개방데이터 신청 → 인증키 | ⚠ **XML/LINK 방식이라고만 확인**, 실제 스트림 규격(HLS 여부 등)은 미확인. ITS와 별개 창구라 **커버리지가 다를 가능성** — 부울경 지점 존재 여부 확인 필요 |
| 3 | **서울시 실시간 인구데이터 (data.seoul.go.kr / 스마트서울맵)** | KT·SKT·신한카드 기반 유동인구 **밀집도 수치** | 탐지엔 못 씀(영상 아님) | 열린데이터광장 인증키 | **영상이 아니라 숫자**입니다 — 우리 서비스의 "탐지" 자체엔 쓸 수 없고, **CCTV 기반 탐지 결과를 검증하는 참고 지표**로만 유효 |
| 4 | **강남구 데이터강남 플랫폼 실시간 도시현황** | 자체 방범 CCTV + AI(피플카운팅·인파밀집 등 7종) | 이미 매우 정교함 | 강남구 자체 운영, 외부 제공 없음 | ⚠ **자체 시스템**이라 2-1절과 같은 이유로 외부 반출 불가. "참고 사례"로만 의미 있음 — 우리 인파 판정 문턱(현재 93.6% 쏠림 문제, `pending_tasks.md` 3-8) 재설계 시 벤치마크로 참고할 가치는 있음 |
| 5 | 부산 등 지자체 **관광 실시간 CCTV**(해운대·광안리) | 관광 홍보용 | 중간 | `cctv-world.kr`·`pyony.com`·`viewmaplive.com` 등 **민간 애그리게이터를 통해서만 접근 확인됨** | ⚠ **이 사이트들이 정부·지자체 공식 소스를 재전송하는 것인지, 저작권·이용약관 근거가 무엇인지 이번 조사로 확인하지 못했습니다.** 공공기관 납품 산출물의 근거로 쓰려면 원본 소스(부산시 관광 API 등)를 별도로 찾아 확인해야 합니다 |

## 3. 해외

| # | 소스 | 국가 | 성격 | 인파관리 적합도 | 이용 조건 |
|---|---|---|---|---|---|
| 1 | **TfL JamCams** | 영국(런던) | 교차로·터널·교량 CCTV 900개+ | **★★ 가장 유력** | `api.tfl.gov.uk/Place/Type/JamCam/` — **TfL Open Data Licence**(무료), "Powered by TfL Open Data" 표시 의무. **보행자·차량 검출 학술 연구 선례 있음**(YOLOv3 적용 사례, Imperial College). ⚠ 진짜 실시간 영상이 아니라 **5~10분 간격 정지영상** |
| 2 | **NYC DOT 교통 카메라** | 미국(뉴욕) | 5개 자치구 교차로 CCTV | 중간 | `nyctmc.org`(정지영상 직접 접근) / `511NY` REST API(개발자 키 필요) / NYC Open Data | ⚠ 상업적 이용 관련 상세 약관은 이번 조사로 확인하지 못함 — `nyctmc.org` "Terms of Use" 원문 확인 필요 |
| 3 | **TrafficLand** | 미국 전역 | 주·지방 DOT 카메라 통합 유통사 | 중간 | 50개+ 주정부 DOT와 **계약 기반 재배포** — **무료 개방 API가 아니라 유상 라이선스 사업**으로 보임 | ⚠ 구체적 요금·약관은 영업팀 문의 필요. 국내 사업에 해외 유상 API를 쓸 이유는 낮음 |
| 4 | 일본 국토교통성 도로 라이브카메라 | 일본 | 지방정비국별 도로 CCTV | 낮음(위치 안내 중심) | `jice.or.jp` 지도뷰어로 위치만 확인됨 | ⚠ **실제 이미지 API 접근 방식을 이번 조사로 확인하지 못함.** JARTIC(`jartic-open-traffic.org`)은 **교통량 수치 API**만 확인됨(영상 아님) |
| 5 | **EarthCam** | 전세계(주로 미국) | 상업 웹캠 네트워크(타임스퀘어 등 유명 지점) | 화면상으로는 적합해 보이나 | — | **✗ 사용 불가 — 상업적/자동화 이용 사전 서면 승인 필수**. 캡처·녹화·재전송·임베드 전부 명시적으로 금지. AI 탐지 파이프라인에 넣는 것 자체가 약관 위반 소지 |
| 6 | Insecam 류 애그리게이터 | 전세계 | 비밀번호 미설정 무방비 카메라 재전송 | — | — | **✗ 사용 불가 — 권고하지 않음**. 카메라 소유자 동의 없이 무단 노출된 개인 카메라를 모은 것으로, 각국 개인정보보호기관이 폐쇄를 요구한 이력이 있는 서비스입니다. 공공기관 납품 산출물의 데이터 출처로 쓸 수 없습니다 |

## 4. 종합 판단 — 무엇을 다음에 할지

| 우선순위 | 항목 | 이유 |
|---|---|---|
| 1 | **국립해양조사원 「안전해」 CCTV 개방 여부 문의** | 여름철 해수욕장 인파는 실제 배치 환경(부울경 해안)과 가장 비슷한 화각·상황. 전화 문의(051-773-5694)로 API 개방 여부만 확인하면 됨 — 비용 없음 |
| 2 | **TfL JamCams로 소규모 검증** | 무료·공식 오픈데이터, 정지영상이라도 인파 탐지 학습·검증용으로는 충분. 「인파관리」 모델이 아직 mock 모드인 상태(`docs/202608250759/detection_tech_stack.md` 참고)에서, **도로가 아닌 화각의 실사용 이미지**를 처음으로 확보하는 계기가 될 수 있음 |
| 3 | **경찰청 UTIC API 신청 검토** | ITS와 별개 창구라 부울경 커버리지가 다를 가능성 — 신청 전에 담당자 문의로 실익부터 확인 |
| 4 | 관광 CCTV 애그리게이터(cctv-world.kr 등) | **근거·약관이 불명확**해 지금 단계에서는 보류. 원 소스(부산시 등)를 못 찾으면 쓰지 않는 편이 안전 |
| — | EarthCam · Insecam류 | **제외** — 위 사유로 검토 대상에서 뺌 |
