## 0. 결론 먼저

○ **설계 그대로 구현했고, 추가 설치는 결국 0개입니다.**
  설계서는 `ltree` 하나를 쓰기로 했으나 **안 쓰고도 됐습니다**

○ ★ **시험이 실제 결함 하나를 잡았습니다.** 인접 탐색이 **출발 지점을 결과에
  되돌려 넣고** 있었습니다. 화면에 붙였다면 「인접 카메라 목록에 자기 자신」이
  나왔을 것입니다

○ **기존 동작은 하나도 안 바뀌었습니다.** 표는 전부 비어 있고, 비어 있으면
  지금과 똑같이 돕니다. 회귀 1,076건이 그대로 통과한 것이 그 증거입니다

○ ⚠️ **표를 만들었다고 쓰이는 것은 아닙니다.** `hazard_sop_map` 은 아직
  **읽는 코드가 없고**, `risk_levels` 도 판정에 연결되지 않았습니다

## 3. ★ 시험이 잡은 결함

`neighbors()` 의 재귀 CTE 가 **출발 지점을 결과에 되돌려 넣고** 있었습니다.

인접은 양방향이라 `A → B → A` 로 **두 홉 만에 자기 자신**이 됩니다.
`depth > 0` 만으로는 안 걸러집니다 — 되돌아온 A 는 depth 2 이기 때문입니다.

```sql
 WHERE depth > 0
   AND camera_id <> CAST(:start AS varchar)   -- ← 이 줄이 없었다
```

`test_neighbors_two_hop_reaches_c` 가 잡았습니다.
**화면에 붙이기 전에 잡혀 다행입니다.**

## 4. ⚠️ 설계와 달라진 것 4가지

| # | 설계 | 구현 | 이유 |
|---|---|---|---|
| 1 | `zones.path` 를 **`ltree`** 로 | **`varchar` + `LIKE`** | **추가 설치가 0** 이 된다. 경남이 도+18시군이라 수백 행이라 성능 차이 없음 |
| 2 | 어휘를 **마이그레이션에** | **`core/vocabulary.py` 로 분리** | 시험 DB 는 속도 때문에 `create_all` 을 써서 마이그레이션을 타지 않는다. 오류 코드 사전·SOP 가 이미 쓰는 방식과 같게 맞춤 |
| 3 | `hazard_types` 칸 | **`detectable` 추가** | 어휘 등록과 탐지 가능은 다르다 |
| 4 | 위험유형 7행 | **11행** | 상위 코드(`flood`·`crowd`·`road`)가 없으면 「침수 전체」로 묶어 볼 수 없다 |

> 1번이 가장 중요합니다. **설계서보다 나은 결과**입니다 —
> 폐쇄망 납품에서 설치 대상 0 은 그 자체로 값어치가 있습니다.

### 시험이 못박은 것

| # | 내용 |
|---|---|
| 1 | **비어 있어도 예외 없이 빈 목록**을 준다 — 없는 카메라를 물어도 마찬가지 |
| 2 | **인접은 양방향, 상·하류는 단방향** — A 의 하류가 B 라고 B 의 하류가 A 는 아니다 |
| 3 | **홉 제한이 실제로 걸린다** — 순환해도 끝난다 |
| 4 | 여러 경로로 닿으면 **가장 짧은 깊이**를 준다 |
| 5 | 인접을 물었는데 **상·하류가 섞여 나오지 않는다** |
| 6 | 자동 생성은 **`auto=True` 만 지운다** — 사람이 넣은 상·하류가 살아남는다 |
| 7 | 두 번 돌려도 **링크가 두 배가 되지 않는다** |
| 8 | **센서 하나에 카메라 여럿**이 붙는다 (경남 SFR-005 의 N:1) |
| 9 | **대표 센서가 앞에** 온다 |
| 10 | `kr.busan` 이 **`kr.busanjin` 을 끌어오지 않는다** |
| 11 | **어휘 label 이 현재 코드값과 같다** — 어긋나면 화면과 표가 따로 논다 |
| 12 | **산불·태풍이 `detectable=False`** 로 표시된다 |

## 6. ⚠️ 좌표 결함이 그대로 남아 있습니다

`build_adjacency()` 가 **거리 0인 쌍을 세어서 알려 줍니다**(`zero_distance_pairs`).

앞서 확인된 데이터 결함 — 범내골교차로와 광복로·광복로1 이 **같은 좌표**를
가지고 있습니다(`docs/202608171820`). 자동 생성이 이걸 조용히 이웃으로 묶으면
**서로 다른 지점이 한 덩어리**가 됩니다.

> **여기서 고치지 않았습니다.** 정확한 좌표를 모르는데 지어내면 안 됩니다.
> 세어서 드러내는 데까지가 코드가 할 일입니다. 시험으로도 묶어 뒀습니다
> (`test_zero_distance_pairs_are_reported`).
