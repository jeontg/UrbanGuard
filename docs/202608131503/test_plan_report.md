> 관제 시스템이 **네트워크 블립에 통째로 죽었고, 밤사이 아무도 몰랐습니다.**

### 5-1. ★ 가장 시급한 미시험 3건

**① 실검출 전환 후 인파 정확도 (1번)**
지금 화면에 나오는 인원·위험행동은 **실제 영상값이 아닙니다.** 실검출로
바꾼 뒤 현장 캘리브레이션과 정확도 측정이 필요합니다.

**② 다수 지점 상시 탐지 시 CPU (7번)**
상시 탐지를 3개 도메인으로 확대했지만, **지점 1개소로만 시험했습니다.**
지점당 스레드가 붙는 구조라 여러 곳을 켜면 부하가 선형 이상으로 늘 수
있습니다. 시범운영 규모를 정하기 전에 측정이 필요합니다.

**③ 장시간 연속 운전 (8번)**
관제 시스템은 24시간 돕니다. 수 시간 이상 연속 운전에서 메모리 누수나
스트림 끊김 후 복구를 확인하지 않았습니다.
