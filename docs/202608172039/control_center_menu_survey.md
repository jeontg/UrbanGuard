## 1. ⚠️ 먼저 — 조사의 한계

**구체적인 메뉴 트리를 찾지 못했습니다.** 시도한 것과 막힌 지점입니다.

| 대상 | 결과 |
|---|---|
| **KT 기업형 CCTV 통합관제 (GiGAeyes pro)** | ✅ **성공** — 16.9MB PDF 내려받아 8쪽 전문 추출 (4절) |
| 한화비전 Wisenet SSM 한글 매뉴얼 | ⚠️ **글꼴 매핑 없어 텍스트 깨짐**(CID 인코딩) |
| 한화비전 SSM Console 영문 매뉴얼 | **404** |
| Wisenet WAVE 온라인 도움말 | 다운로드 페이지만 (매뉴얼 본문 아님) |
| 공간정보 기반 CCTV 통합운영 웹서비스 (KAIA) | **본문 전달 실패** |
| 조은테크 통합관제 솔루션 | **SSL 인증서 오류** |
| 스마트시티 에코 통합플랫폼 | 모듈 구성만 확인 (메뉴 없음) |
| 이노뎁 VURIX | 제품 개요만 확인 (메뉴 없음) |
| 지자체 CCTV 통합관제 **제안요청서** | **공개본 없음** |

> **웹 페치가 10MB 를 넘으면 거부됩니다.** KT 자료는 그 때문에 처음 실패했는데,
> **직접 내려받아 텍스트 레이어를 뽑으니 됐습니다.** 같은 방법을 다른
> 제품에도 썼으나 **글꼴 매핑이 없는 PDF**(한화비전 한글본)는 글자가
> 깨져 못 읽었습니다.

**왜 안 나오는가** — 관제 시스템의 화면 설계서는 **발주처 산출물**이라
공개되지 않고, 벤더 홈페이지는 기능 소개 수준에 머뭅니다.

> **지어내지 않았습니다.** 그럴듯한 메뉴 트리를 만들어 제안서에 넣으면
> 발주처가 자기 시스템과 대조하는 순간 무너집니다.

**확실히 얻으려면** — 조달청 나라장터의 **제안요청서(RFP)** 나 **과업지시서**를
받아 보는 것이 정확합니다. 부울경 지자체 CCTV 통합관제 관련 공고를 뒤지면
「화면 목록」이 붙어 있는 경우가 있습니다.

## 2. 확인된 것 — 정부가 정한 서비스 골격

메뉴보다 **위의 층위**에서 표준이 있습니다.

### 2-1. ★ 스마트시티 통합플랫폼 5대 연계서비스

지자체 통합플랫폼이 갖춰야 할 **공공안전 연계** 표준입니다.

| # | 서비스 | 내용 |
|---|---|---|
| 1 | **112 (경찰)** | 방범 상황 대응 |
| 2 | **119 (소방)** | 화재·구조 상황 대응 |
| 3 | **재난망 (NDMS)** | 각종 재난 상황 대응 |
| 4 | **사회적 약자 지원** | 취약계층 보호 |
| 5 | **긴급영상지원** | CCTV 영상정보 공유 |

목적은 **「긴급상황 시 골든타임 확보」**이며, 112·119 상황실에서 일선
경찰서·소방서까지 **실시간 영상정보 공유**를 넓히는 방향입니다.

### 2-2. 통합플랫폼의 모듈 구성

「스마트시티 에코 통합플랫폼 v1.8」기준 **4개 핵심모듈**입니다.

| 모듈 | 하는 일 |
|---|---|
| **센터·정보시스템 연계 처리** | 외부 기관·시스템과 주고받기 |
| **도시 상황정보 수집·표출** | CCTV·교통·기상·시설물 |
| **관제업무 지원** | 관제요원이 실제로 쓰는 화면 |
| **데이터 관리** | 저장·조회·정리 |

**이벤트 26종**을 지원한다고 명시돼 있습니다.

### 2-3. 실시간 감시 화면의 통상 사양

| 항목 | 확인된 내용 |
|---|---|
| 화면 분할 | **최대 64채널** · 듀얼 모니터 시 **128채널** |

| 이벤트 | 발생 시 **실시간 영상 팝업** |

### 2-4. 제도·표준

|---|---|
| **지방자치단체 영상정보처리기기 통합관제센터 구축 및 운영규정** | 행정안전부 |

### 그때와 달라진 것 — 규격 확보 경로

당시 남은 과제가 **「5대 연계 기술 규격 — 공개 자료 없음」** 이었습니다.
이번 조사에서도 **규격은 못 찾았습니다.** 다만 **메뉴가 아니라 규격이
막힌 것**이 분명해졌습니다.

**다만 이것이 곧 약점은 아닙니다.** 5대 연계는 **통합플랫폼이 하는 일**이고,
우리는 그 플랫폼에 **넣을 탐지 엔진**일 수 있습니다. 제안 위치를 어디로 잡을지에
따라 필요 여부가 갈립니다.

### 4-2. 우리가 더 갖춘 축

일반 VMS·통합관제에서 **보기 어려운** 것들입니다.

| 화면 | 왜 특이한가 |
|---|---|
| **영상 반출 관리대장 (S-94)** | ⚠️ **반출 시 마스킹 자체는 상용에도 있습니다**(KT 특화 VA). 우리 차별점은 **마스킹이 아니라 「대장」** — 누가 왜 반출했는지 남기는 쪽입니다 |
| **디지털 SOP (S-86)** | 대응 절차를 화면에 박아 둠 |
| **교대 인수인계 (S-04)** | 관제요원 교대 시 정보 유실 방지 |
| **증거 영상 관리 (S-88)** | 등급별 보존·파기 |
| **오류 코드 사전 (S-93)** | 장애를 코드로 관리 |
| **AI 모델 운영 (S-61)** | 모델을 화면에서 고르고 시험 |

> **「관제 이후」를 다루는 화면이 많습니다.** 대부분의 VMS 가 「보는 것」에
> 집중하는 데 비해, 우리는 **본 다음에 무엇을 하고 무엇을 남기는가**에
> 화면을 배정했습니다. 규제 강화 흐름에서는 이쪽이 유리합니다.

### 4-3. 통상 사양 대비 확인이 필요한 것

| 항목 | 통상 | UrbanGuard |
|---|---|---|
| 화면 분할 | 64~128채널 | ⚠️ **미확인** — 상시 7지점 기준으로 만들어짐 |
| 사용자 정의 배치 | 있음 | ⚠️ **없음** (카드 정렬 고정만 있음, S-85) |
| 이벤트 팝업 | 있음 | ⚠️ **미확인** |

> 그래도 **발주 사양서에 「64분할」이 적혀 있으면 그대로 요건**이 됩니다.
