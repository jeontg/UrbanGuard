## 1. 정정 — 흐름은 이미 있었습니다

`docs/202608170920/tech_trends.md`, `docs/202608171242` 등에서
**「인파 흐름(속도·방향) 부재」** 를 최대 공백으로 적었습니다.
**코드를 확인한 결과 사실이 아닙니다.**

### 실제 상태

`CrowdBehaviorTracker` 가 트랙별 속도 벡터 `(vx, vy)` 를 뽑아 네 지표를
계산하고, `SemanticRiskAgent` 가 **넷을 모두 위험도 산출에 씁니다.**

| 지표 | 뜻 | 위험도 가중치 |
|---|---|---|
| 밀집도 | 사람이 얼마나 빽빽한가 | **35%** |
| `surge` | 평소 대비 속도 배수 | **25%** |
| `dispersion` | 방향이 얼마나 흩어졌나 | **20%** |
| `divergence` | 중심에서 퍼지나(+) 모이나(−) | **20%** |

판정 규칙도 흐름을 씁니다.

```
발산도 > 6.0 이고 속도급증 > 1.3   → 패닉움직임(PANIC_DISPERSION)
속도급증 > 1.6                     → 군중급증(CROWD_SURGE_RISK)
방향분산 > 0.6                     → 이동흐름혼란(FLOW_CHAOS)
밀집도 > 40                        → 군중밀집(CROWD_DENSITY_HIGH)
```

### 그러면 무엇이 빠져 있었나

**계산은 하는데 밖으로 안 나갔습니다.** `CrowdSnapshot` 이
`mean_speed` 와 `dispersion` 만 담아, 관제요원은 **결과만 보고 근거는 볼 수
없었습니다.**

> **제안서·계획서에서 「흐름이 없다」고 쓰면 안 됩니다.** 있습니다.
> 정확한 표현은 **「흐름 기반 시계열 예측이 없다」** 입니다 — 지금 값으로
> 판정은 하지만 **몇 분 뒤를 내다보지는 않습니다.**

## 2. ⚠️ 발견한 결함 — 위험도 점수가 항상 0.0

### 증상

```
assess() 반환 키 : context, drivers, risk_code, risk_name_kr, score, severity
score      = 0.947
risk_score = None          ← 받는 쪽이 찾던 키
```

`live_analyzer.py` 가 `assessment.get("risk_score", 0.0)` 로 읽어
**항상 0.0** 이 들어갔습니다.

### 왜 안 보였나

**등급은 정상이었습니다.** `risk_code` 와 `severity` 는 제 키를 써서 제대로
동작했고, 화면의 위험 등급·색상도 맞았습니다. **숫자 하나만 0** 이라
「원래 그런가 보다」로 넘어가기 쉬웠습니다.

### 고친 방법

```python
risk_score=float(assessment.get("score",
                                assessment.get("risk_score", 0.0)))
```

**시험으로 못박았습니다** — 판정기 반환 키가 바뀌면 바로 걸립니다.

> 이런 종류가 가장 위험합니다. **죽지 않고 조용히 0을 흘립니다.**

## 3. 화면에 올린 것

| 항목 | 표시 |
|---|---|
| `surge` | **속도급증 1.8배** |
| `divergence` | **발산도 7.5** |
| `drivers` | **판정 근거** 「발산도UP」「속도급증」「밀집도UP」 칩 |

### 왜 근거를 보여야 하나

관제요원이 「군중급증 0.72」만 보면 **오탐인지 실제인지 가릴 수 없습니다.**
근거가 보이면 「발산도가 올랐다면 사람들이 흩어지는 중이겠다」처럼
**화면과 대조해 판단**할 수 있습니다.

이 프로젝트가 계속 지켜 온 **근거 표기** 원칙과 같은 자리입니다. 국가 사업의
**XAI(설명 가능)** 방향과도 맞습니다.

### 시험이 못박은 것

- 판정기가 **`score` 키**로 점수를 돌려준다 (키 계약)
- 판정기가 **근거를 함께** 돌려준다
- **네 지표가 실제로 점수를 움직인다** — 하나라도 무시되면 걸린다
- 스냅샷이 흐름 지표와 근거를 담는다
- 근거가 없어도 **키는 있다** (화면이 없는 키를 참조하면 카드가 통째로 안 그려진다)
- **`surge` 기본값이 1.0** — 0이면 「속도가 0배」가 되어 판정이 뒤집힌다
- **빈 화면이 급증으로 읽히지 않는다**
- 화면이 근거를 **실제로 그린다** (만들어 놓고 안 부르면 안 보인다)
