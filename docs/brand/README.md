# UrbanGuard 브랜드 자산

> 생성 2026-08-07 · 재생성 스크립트는 대화 기록의 `make_logo.py` 참조

## 컨셉

**방패(Guard) 안에 도시 스카이라인(Urban).**

- 색상은 제품 관제 UI 팔레트를 그대로 씁니다 — 다크 네이비 `#0F1420` + 액센트 블루 `#4F8CFF`
- 감시(눈·카메라) 도상을 쓰지 않았습니다. 인파관리의 배회 탐지가 개인 행동 추적이라
  개인정보 쟁점이 있어, **지킨다는 인상**으로 잡았습니다(명칭 선정과 같은 이유)
- 건물은 폭·높이·머리 모양을 서로 다르게 두었습니다. 같은 폭 막대 3개는
  스카이라인이 아니라 **막대그래프로 읽힙니다**

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `urbanguard_logo_dark.png` | 900×290 | 가로형 · **다크 배경용** (관제 화면·표지) |
| `urbanguard_logo_light.png` | 900×290 | 가로형 · **밝은 배경용** (제안서·문서) |
| `urbanguard_stacked_dark.png` | 640×500 | 세로형 · 다크 배경 |
| `urbanguard_stacked_light.png` | 640×500 | 세로형 · 밝은 배경 |
| `urbanguard_mark.png` | 512×512 | 심볼 단독 (배경판 없음) |
| `urbanguard_appicon.png` | 512×512 | 앱 아이콘 (둥근 배경판) |
| `urbanguard_favicon_512.png` | 512×512 | **단순화 심볼** — 작은 크기 전용 원본 |
| `urbanguard_icon_16~256.png` | 각 크기 | 파비콘 |
| `urbanguard.ico` | 다중 | 브라우저 탭 |
| `urbanguard_preview.png` | 1400×980 | 전체 미리보기 시트 |

**16~48px 아이콘은 큰 로고를 축소한 것이 아니라 따로 그렸습니다.** 첨탑·계단 같은
디테일은 그 크기에서 뭉개지므로, 획을 굵게 하고 건물을 둘로 줄인 별도 버전입니다.

## 사용 규칙

- **다크/라이트 버전을 배경에 맞춰 쓰세요.** 다크용은 `Urban`이 흰색이라
  흰 배경에서는 보이지 않습니다
- 최소 크기: 가로형 **높이 28px** 이상, 심볼 **16px** 이상
- 로고 주변 여백은 심볼 높이의 **1/4 이상** 확보
- 색상 변경·기울이기·그림자 추가는 하지 마세요

## 적용 위치 (코드)

- 로그인 화면 로고 — `service/templates/login.html`
- 상단 브랜드바 — `service/templates/_layout.html`
- 파비콘 — 위 두 템플릿의 `<link rel="icon">`
- 서비스되는 사본 — `service/static/brand/`
