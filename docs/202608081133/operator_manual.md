## 1. 시작하기

### 1-1. 접속

브라우저에서 관제 서버 주소로 접속하면 로그인 화면이 나옵니다.

> **⚠️ 비밀번호를 5회 틀리면 10분간 잠깁니다.** 잠기면 시스템관리자에게
> 비밀번호 재발급을 요청하십시오.

### 1-2. 최초 로그인 — 비밀번호 변경

계정을 처음 받으면 **임시 비밀번호**입니다. 로그인하면 비밀번호 변경 화면이
뜨고, **바꾸기 전에는 다른 화면으로 갈 수 없습니다.**

비밀번호 규칙
- 9자 이상
- 영문 대문자·소문자·숫자·특수문자 중 **3종류 이상**

### 1-3. 내 권한 확인

화면 오른쪽 위에 이름과 역할이 표시됩니다. 역할에 따라 **보이는 메뉴가
다릅니다.** 권한이 없는 메뉴는 비활성이 아니라 **아예 나오지 않습니다.**

| 역할 | 할 수 있는 일 |
|---|---|
| **관제요원 (OPR)** | 전 도메인 관제, 탐지 실행, 알림 **요청** |
| **부서담당자 (MGR)** | 담당 도메인 관제·설정, 알림 **발송**, 시설물 제어 |
| **시스템관리자 (SYS)** | 전 기능 + 계정 관리 + 시스템 설정 |

> **관제요원은 주민 경보를 직접 보낼 수 없습니다.** 요청만 가능하며 다른
> 사람이 승인해야 발송됩니다. 야간 1인 근무 시 단독 발송을 막기 위한 장치입니다.

## 3. 일상 관제 업무

### 3-1. 통합 상황판 (S-01)

근무 시작 시 처음 보는 화면입니다. 세 도메인의 현재 상태를 한눈에 보여줍니다.

확인 순서
1. **위험 등급이 올라간 지점**이 있는가
2. **처리하지 않은 이벤트**가 있는가
3. **승인 대기 중인 알림**이 있는가

> **⚠️ 화면 수치가 실제 분석 결과인지 확인하십시오.** 인파 검출이 모의(mock)
> 상태면 화면에 경고가 뜹니다. **그 상태의 인원 수는 실제 영상값이 아닙니다.**

### 3-2. 이벤트 처리 (S-02 · S-03)

이벤트는 「사건」 단위입니다. 같은 지점에서 위험이 이어지면 **새로 만들지 않고
갱신**되므로 목록이 도배되지 않습니다.

처리 흐름

```
 [발생]  탐지가 이벤트를 만듦
    ↓
 [확인]  관제요원이 열어 보고 담당 지정
    ↓
 [조치]  현장 확인 · 시설물 제어 · 알림 요청
    ↓
 [종결]  처리 완료 또는 오탐 표시
```

**등급이 내려가도 최고 등급(`peak_level`)은 남습니다.** 위험이 지나간 뒤에도
그 사건이 얼마나 심각했는지 알 수 있어야 사후 보고가 가능하기 때문입니다.

**오탐이라고 판단되면 반드시 「오탐」으로 표시하십시오.** 모델 개선의 근거가
됩니다.

### 3-3. 인파 선택 탐지 (S-30)

인파관리 화면 맨 위 「CCTV 선택 탐지」에서 지점을 골라 실행합니다.

1. 지점 선택
2. **「▶ 분석 실행」** 클릭
3. **30초 관측** — 남은 시간이 카운트다운으로 표시됩니다
4. 결과 확인

> **⚠️ 30초 동안 화면이 멈춘 것처럼 보여도 새로고침하지 마십시오.**
> 버튼에 남은 초가 표시됩니다.

**결과 읽는 법**

| 항목 | 의미 |
|---|---|
| 인원 최대·평균 | 관측 구간의 값 |
| 밀집지수 최대 | 격자 기준 밀집도 |
| 위험등급 | **관측 구간에서 가장 위험했던 순간**의 등급 |
| 탐지된 위험행동 | 배회·침입 |
| 관측 마지막 화면 | **사람 영역이 가려진 상태**로 표시 |

> **⚠️ 「침입 구역 미설정」 표시가 있으면 침입은 탐지되지 않습니다.**
> 밀집도·배회만 분석됩니다. ROI 설정이 필요합니다(5-3절).

> **⚠️ 관측 30초에 분석 프레임이 5장 정도로 적습니다.** 검출이 느려 표본이
> 얇습니다. **단독 근거로 삼지 말고 영상을 함께 확인하십시오.**

**동시에 두 곳을 분석할 수 없습니다.** 다른 사람이 실행 중이면 안내가 뜹니다.

### 3-4. 노면 AI 탐지 (S-41)

모드를 고르고 실행합니다.

| 모드 | 설명 | 소요 |
|---|---|---|
| 기존 영상 | 파일 전체에서 12장 표본 | 수십 초 |
| 실시간 CCTV | **15초 관측** | 20~30초 |

> **⚠️ 현재 모델은 부산 CCTV에서 탐지 0건입니다.** 오류가 아니라 학습
> 데이터와 촬영 조건이 달라 생긴 한계입니다. **0건이 곧 「손상 없음」을
> 뜻하지 않습니다.** 화면에도 이 안내가 표시됩니다.

### 3-5. 현장 제보 확인 (S-43)

시민·직원이 올린 제보를 확인하고 처리합니다.

> ### ⚠️ 사진 확인 시 반드시 알아 두십시오
> **사람은 자동으로 가려지지만 차량번호판은 가려지지 않습니다.**
> 전용 모델이 없어 **육안으로 확인**해야 합니다. 번호판이 보이면 외부로
> 공유하지 마시고 담당자에게 알리십시오.

마스킹에 실패한 사진은 화면에 경고가 표시됩니다. 그 상태의 사진은 개인정보가
그대로 담겨 있을 수 있으니 취급에 주의하십시오.

## 4. 대응 업무

### 4-1. 알림 요청과 승인 (S-50)

#### 요청 (누구나 가능)

이벤트 상세에서 통보를 요청합니다. 대상은 세 가지입니다.

| 계층 | 대상 |
|---|---|
| 내부 | 관련 부서 |
| 기관 | 112·119·재난상황실 |
| **주민** | **문자·알림톡** |

#### 승인 (요청자 본인은 불가)

> ### ★ 주민 경보는 2인 승인입니다
> **요청한 사람은 자기 요청을 승인할 수 없습니다. 역할과 무관합니다.**
> 시스템관리자도 자기가 요청한 건은 승인하지 못합니다.

승인 대기함에서 내용을 확인하고 승인 또는 반려합니다. 반려 시 사유를 남기십시오.

#### 「심각」 단계 단독 발송

급박해서 승인자를 기다릴 수 없을 때만 사용합니다.
**사후 승인 대상으로 표시되고 감사 로그에 남습니다.** 남용하지 마십시오.

> **⚠️ 기관 통보(112·119·재난상황실)는 요청까지만 기록됩니다.**
> 시스템이 자동으로 전송하지 않습니다. **기존 절차(유선 등)로 직접
> 처리하셔야 합니다.** 시스템에는 요청 사실과 승인 이력만 남습니다.

### 4-2. 시설물 원격제어 (S-11)

세 가지 모드가 있습니다.

| 모드 | 동작 |
|---|---|
| **권고만** | 「무엇을 해야 하는지」만 표시. **제어하지 않음** |
| 원격요청 | 담당자 확인 후 명령 전송 |
| 자동 | 조건 충족 시 자동 제어 |

> **기본값은 「권고만」입니다.** 차단기·경보기 오작동은 사람이 다칠 수
> 있습니다. **모드 변경은 시스템관리자만 가능합니다.**

## 5. CCTV 관리 (S-80 · S-81) ★

설정 권한(MGR·SYS)이 있어야 합니다.

### 5-1. CCTV 등록

「+ CCTV 등록」을 펼치고 입력합니다.

| 항목 | 설명 |
|---|---|
| **ID** | `CAM-SEOMYEON` 형태. **대문자로 시작, 나중에 바꿀 수 없음** |
| 이름 | 서면교차로 |
| 담당 부서 | 도로관리과 — **부서담당자 권한 범위 판정에 쓰입니다** |
| 위도·경도 | 국내 범위만 허용 (위도 33~39, 경도 124~132) |
| 소스 종류 | `hls` (실시간) / `video` (파일) |
| 주소·경로 | 소스 종류에 맞게 |

> **⚠️ ID는 등록 후 변경할 수 없습니다.** 과거 이벤트와의 연결이 이 값으로
> 유지되기 때문입니다. 신중하게 정하십시오.

### 5-2. 탐지서비스 지정 — 3단계

「탐지 지정」 버튼을 누르면 세 서비스가 나옵니다.

```
 ☑ 침수·교통위험
     ☑ 상시 탐지
 ☑ 인파관리
     ☐ 상시 탐지
 ☐ 도로 노면 관리
     ☐ 상시 탐지
```

| 단계 | 의미 |
|---|---|
| **① 서비스 체크** | 이 서비스가 이 지점을 **쓴다** |
| **② 상시 탐지 체크** | 요청 없이도 **계속 본다** |

**서비스만 체크하고 상시를 끄면** 「선택 탐지」입니다 — 관제요원이 화면에서
지점을 골라 실행할 때만 분석합니다.

#### 도메인별 상시 탐지 주기

| 도메인 | 주기 |
|---|---|
| 침수 | 연속 (초당 약 5회) |
| 인파 | 지점당 5초 간격 |
| 노면 | 지점당 15분 |

> ### ⚠️ 상시 탐지를 바꾸면 서비스를 재시작해야 반영됩니다
> 분석 중인 프로그램을 실행 중에 바꾸면 추적 상태가 어긋나기 때문입니다.
> 저장 후 화면에 안내가 뜹니다. **시스템관리자에게 재시작을 요청하십시오.**

> ### ⚠️ 상시로 켠 지점 수만큼 서버가 힘들어집니다
> 특히 인파는 지점마다 별도 처리가 붙습니다. **여러 곳을 한꺼번에 켜지 마시고,
> 늘릴 때마다 서버 상태를 확인**하십시오.

### 5-3. ROI 설정 (S-81)

ROI는 **「영상의 어느 부분을 볼 것인가」**입니다. 서비스마다 보는 곳이 다르므로
**도메인 탭으로 나뉘어 있습니다.**

| 도메인 | 영역 | 필수 |
|---|---|---|
| 침수 | **도로 ROI** | **✅ 필수** |
| | 저지대 ROI | 선택 |
| | 차선 기준선 | 선택 |
| 인파 | 침입 금지 구역 | 선택 |
| 노면 | 노면 분석 구간 | 선택 |

**그리는 방법**

1. 도메인 탭 선택
2. 「영역 종류」 선택
3. 영상을 클릭해 꼭짓점 찍기
4. **「다각형 닫기」**로 영역 완성 (선은 점 2개)
5. **「저장」**

> **⚠️ 침수는 도로 ROI가 없으면 저장되지 않습니다.** 물이 어디에 찼는지
> 판단할 기준면이 없기 때문입니다.

> **⚠️ 정지영상이 안 나오면** 그 카메라의 영상이 아직 들어오지 않은 것입니다.
> **상시 탐지가 꺼진 카메라는 영상이 들어오지 않습니다.** 잠시 상시 탐지를
> 켜거나 스트림 상태를 확인하십시오.

> **⚠️ ROI 저장도 재시작해야 탐지에 반영됩니다.**

### 5-4. CCTV 삭제

삭제하면 **탐지서비스 지정과 ROI가 함께 사라집니다.**
**과거 이벤트는 남습니다** — 사건 기록은 지점이 없어져도 보존됩니다.

> 폐지 지점은 삭제 대신 **「사용 안 함」**으로 내리는 것을 권고합니다.

## 6. 계정 관리 (S-90) — 시스템관리자

### 6-1. 계정 생성

| 항목 | 설명 |
|---|---|
| 아이디·성명·부서 | |
| 역할 | SYS / MGR / OPR |
| **담당 도메인** | **MGR에만 의미가 있습니다** |

> **관제요원(OPR)은 담당 도메인을 지정해도 전 도메인을 봅니다.** 상황실에서
> 세 가지를 모두 봐야 하기 때문입니다. 도메인 제한은 부서담당자에게만
> 적용됩니다.

**임시 비밀번호가 한 번만 표시됩니다.** 본인에게 안전하게 전달하십시오.

### 6-2. 퇴직·전보 처리

**계정을 삭제하지 말고 「사용 안 함」으로 내리십시오.**
삭제해도 감사 기록은 남지만, 비활성화가 더 안전합니다.

### 6-3. 감사 로그 (S-91)

| 역할 | 볼 수 있는 범위 |
|---|---|
| SYS | 전체 |
| MGR | **본인 부서만** |
| OPR | 접근 불가 |

기록되는 것 — 로그인·계정변경·**알림 요청/승인/발송**·설정변경·탐지실행·보고서 출력

| 상황 | 확인 |
|---|---|
| 인원 수가 이상하다 | 화면에 **모의(mock) 경고**가 있는지 확인. 있으면 실제 값이 아님 |
| 노면 탐지가 항상 0건 | **모델 한계입니다.** 0건이 「손상 없음」이 아님 |
| 상시 탐지를 켰는데 안 돎 | **재시작했습니까?** 「사용」과 「상시」가 둘 다 체크됐습니까? |
| ROI 화면에 영상이 없다 | 상시 탐지가 꺼져 있으면 영상이 들어오지 않습니다 |
| 분석 실행이 안 눌린다 | 다른 사람이 실행 중일 수 있습니다 |
| 내 요청을 내가 승인 못 한다 | **정상입니다.** 2인 승인 규칙 |
| 메뉴가 안 보인다 | 권한이 없는 메뉴는 표시되지 않습니다 |
| 로그인이 자꾸 풀린다 | 시스템관리자에게 문의 (서명 키 설정 문제일 수 있음) |

## 8. ⚠️ 현재 시스템의 한계 (반드시 숙지)

| # | 한계 | 운영 시 유의 |
|---|---|---|
